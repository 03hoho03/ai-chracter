# 공식 작품 댓글 스티커

기존 핑크 `ㄸ` 말풍선 심볼을 표정·손짓으로 의인화한 정적 이미지 8개다.
새 브랜드 로고나 외부 서비스의 캐릭터를 추가하지 않는다. 한국어 문구를 이미지에 넣지 않고
카탈로그의 한국어 이름·대체 텍스트로 의미를 전달한다.

## 원본과 배포 파일

| ID | 이름 | 대체 텍스트 |
|---|---|---|
| `ddona-hello` | 인사 | 손을 흔들며 인사하는 또나 |
| `ddona-thanks` | 감사 | 두 손을 모아 감사하는 또나 |
| `ddona-cheer` | 응원 | 양 주먹을 올려 응원하는 또나 |
| `ddona-happy` | 기쁨 | 양팔을 들고 기뻐하는 또나 |
| `ddona-laugh` | 웃음 | 눈을 감고 배를 잡으며 웃는 또나 |
| `ddona-moved` | 감동 | 눈물을 글썽이며 감동한 또나 |
| `ddona-surprised` | 놀람 | 눈을 크게 뜨고 놀란 또나 |
| `ddona-sad` | 아쉬움 | 팔을 늘어뜨리고 아쉬워하는 또나 |

- 원본: 이 디렉터리의 `{id}.png`, 생성 도구가 저장한 RGBA 원본을 그대로 복사했다.
- 배포: `apps/web/public/comment-stickers/{id}.webp`, 256×256 RGBA, 최대 128 CSS px에서 표시한다.
- URL: `/comment-stickers/{id}.webp`. API는 `frontend_base_url`과 결합한 절대 URL로 제공하여 admin에서도 읽을 수 있게 한다.
- `manifest.json`: ID·한국어 이름·alt·배포 경로 참고값. 런타임 선택 가능 상태와 응답의 기준은 API 카탈로그다.
- `prompts.json`: 내장 `image_gen` 도구에 실제 전달한 생성·표정 변경·명암 보완 프롬프트.
- `validation.json`: 각 원본과 배포 파일의 해시·규격·알파·용량 검사 결과.

## 내보내기

기존 Python/Pillow 환경에서 저장소 루트 기준으로 실행한다. 새 패키지 설치나 API 키가 필요하지 않다.

```sh
python3 apps/web/brand/comment-stickers/export.py
```

전체 정사각 캔버스를 LANCZOS로 256px에 축소하여 손짓·꼬리·여백을 보존한 뒤 lossless WebP로 저장한다.
재로딩한 WebP의 모든 RGBA 바이트가 축소 결과와 같은지 검사한다. 원본 파일을 수정하지 않는다.

## 제작 및 검수 기록

2026-09-30, `$imagegen`의 기본 내장 도구 모드로 각 감정을 따로 생성했다.
파비콘 `favicon-96.png`를 직접 확인한 뒤 인사를 제작하고, 최종 인사 PNG를 나머지 7개의
동일 주인공 참조로 사용했다. 첫 인사본은 어두운 UI에서 눈·입이 묻혀 그 부분과 손짓 표시만
밝은 크림색 테두리로 보완했다. 첫 결과는 `ddona-hello-first-pass.png`에 보존한다.
기쁨은 열린 눈·양팔 만세, 웃음은 감은 눈·배를 잡는 동작이며, 감사는 감은 눈·모은 손,
감동은 열린 눈·작은 눈물로 구분했다. 충분한 결과가 나온 이후 추가 생성은 하지 않았다.

8개 원본 PNG를 각각 `view_image`로 확인했고, 실제 배포 WebP를 128px로 읽은
`preview-128.png`에서 라이트 `#fafafa`·다크 `#0d0d0d` 배경을 확인했다.
이 검수판은 이미지 자체의 크기·표정·투명 배경 검사이며, 댓글 선택·게시·조회 및
실제 web/admin 브라우저 연동 검증은 기능 구현 단계에서 별도로 수행한다.
